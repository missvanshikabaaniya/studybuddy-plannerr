StudyBuddy – Smart Student Planner 📚

About

StudyBuddy is a simple student productivity web app designed to help students organize their daily study tasks and track their progress.

Main Features

- Add study tasks
- Mark tasks as completed
- Track daily progress
- Simple and mobile-friendly interface

Experiment

We will compare two versions:

Version A: Simple task planner.

Version B: Task planner with motivational progress messages.

Experiment Goal

To understand whether motivational progress messages improve task completion.

Technology

- HTML
- CSS
- JavaScript
- Flagsmith
